真实实现（原文照抄自 WaveControler/js/ui.js:368-388）
STOP_WINDOW_MS = 800，状态是 { armed, timer }：
· 引擎没在运行时点一次 → 直接归零，不需要确认（没有误触风险）
· 引擎运行中第一次点击 → 只 arm + 按钮高亮 + 提示，不归零
· arm 状态下第二次点击 → 清除 arm 并归零
· arm 后 800ms 内没有第二次点击 → setTimeout 自动解除 arm

为什么不用 ondblclick：触屏上 dblclick 不可靠， 所以用「两次 click + 时间窗」自己实现。

本页无法覆盖的部分（需要真机 / 真服务器，别把这里的通过当成全部安全验证）：
· 急停闩锁：急停后 AI/远程的控制会被拒绝，必须由被控方点「恢复」才解除
· 与主控失联超过 8 秒 → 被控方立即安全停机（但这是临时停机，链路恢复会自动继续）
· 主控关闭页面时会发 bye，被控方立即停机且不锁定
· 被控方急停永远可用且优先级最高，主控无权解除
这几条的正确性要在真实双端环境里验证（见 remote-selftest.html 与 sync-trace.html）。
