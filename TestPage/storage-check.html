怎么看这份体检：
· 数据只存在浏览器本地。换浏览器、清缓存 / 清站点数据、换域名或端口、无痕模式，都会导致数据丢失 —— 所以请定期点「📤 导出全部为 JSON」做备份。导出的文件里有你的 API 密钥，请自己保管好、不要乱传。
· 状态列：能 JSON.parse 成功 = 正常，解析失败 = 损坏， 值为空字符串 = 空。索引键会额外显示「索引：N 条」。
· file:// 打开时 localStorage 通常可用，但不同 file:// 路径可能被当成不同来源（数据不共享）， 部分浏览器也会限制本地文件写存储。想让「控制器 / 编辑器 / AI 控制器」共用同一份数据，用同一个地址打开它们（例如同一个 http://127.0.0.1 端口）。
· AI 控制器的 settings.js 里有一条「配置损坏就静默重置为默认值」的分支（load() 的 catch）。 所以如果这里看到 ufo.ai.settings.v1 是「损坏」，说明这份配置已经丢过一次了（下次打开 AI 控制器就会被重置为默认值）， 请尽快用备份恢复。
· 字节数按 UTF-16 粗估（字符数 × 2，与 WaveControler/js/store.js 的 bytesOf() 同一算法）， 不是磁盘上的精确占用；navigator.storage.estimate() 那一行才是整个来源的真实用量。
· 导出时若某个键已经损坏，它的原始字符串会被原样保存（键名记在 JSON 的 rawKeys 字段里），恢复时原样写回，不做「修复」。
· 本页只读写 ufo.* 键，自己的探测键 ufo.check.__probe 用完即删、且不计入统计。
