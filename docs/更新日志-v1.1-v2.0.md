# 【更新】UFO 助手 波形控制器 v1.1 / v2.0 更新说明

> 本文可直接用于论坛发帖。两个版本都是波形控制器（🌊）的更新，**脚本播放器（🚀）没有改动**。
> 在线地址见仓库首页；建议用 **Chrome / Edge** 打开（需要 Web Bluetooth）。

---

## 一句话概括

- **v1.1**：把「输出控制」的逻辑摆正 —— 选波形不再自动开输出，修掉几个会让人以为设备坏了的 bug。
- **v2.0**：**新增波形编辑器**，可以在网页上直接画波形了，不用再手写 CSV / JSON。

---

# v1.1 —— 输出控制与试听逻辑修正

这一版没有新功能，全部是修问题。核心是**把「选波形」和「开输出」这两件事彻底分开**。

## 🔧 修复

| # | 问题 | 修复后 |
|---|---|---|
| 1 | 选中波形会自动勾选该通道并开始输出 | 选波形**只做赋值**，不改变输出状态；需自己勾选启用 |
| 2 | 「试一下」写死 2 秒，比 2 秒长的波形会被拦腰切断 | 按波形自身周期**完整播放 2 个周期**，结束自动停 |
| 3 | 「试一下」会干涉急停状态，试听结束后把输出恢复了 | 试听**不再碰引擎启停**；急停就是急停 |
| 4 | **波形结束后没发停机指令** —— 首位不为 0 的波形会让电机一直转 | 周期结束**显式补发停机指令 0,0** |
| 5 | 取消勾选要等下一个 50ms 周期才归零 | 取消勾选**立刻补发停机指令** |
| 6 | 通道未勾选时，示波器播放头还在空转扫描 | 未勾选时播放头**停在起始位置** |
| 7 | 勾选输出时从波形中段开始播，不是从头 | 每通道**独立时间原点**，勾选即从波形开头播 |
| 8 | 只开一个通道时，另一侧示波器中轴不停刷白线 | 禁用通道**不再绘制实发轨迹** |

## 🔄 行为变化

- **连接设备后引擎自动开始运行**，顶部按钮只负责急停 / 暂停，输出完全由两个复选框控制。
- 操作顺序变为：**选波形 → 调强度 / 相位 → 勾选启用**。
- 切换标签页 / 浏览器挂后台 **不再自动停止动作**（详见 v2.0 的「保持前台运行」说明）。

# v2.0 —— 新增波形编辑器

## ✏️ 新功能：波形编辑器

控制器顶部新增 **「✏️ 波形编辑器」** 按钮，新标签页打开。它和控制器**共用同一份本地波形数据**，改完保存，控制器自动就能选到。

### 图形化编辑

- **网格线 + 坐标轴**：左侧是幅度（±125，每 25 一格，**0 在正中间**），底部是时间轴（刻度按周期自动取整）
- 视图固定为「**整个循环周期 × 全幅**」，不做缩放平移 —— 画多少就看多少，不用来回找位置
- **两种画法**
  - **自由绘制**：按住左键在画布上拖，按 50ms 时间步自动落点
  - **两点式折线**：点起点 → 点终点，直接连一条直线
- **精确落点**：状态栏可以输入「时间 / 幅度」回车落点，鼠标怕点歪就用这个
- **断点编辑**：点选 → 拖动 → `Delete` 删除；`Shift + 点击` 插入断点
- **撤销重做**：`Ctrl+Z` / `Ctrl+Y`，或工具栏的 ↶ ↷
- **自动吸附**：靠近幅度 0 / ±127、网格上的每一条刻度、时间 0、循环终点、已有断点时自动吸住（阈值 6 像素），并有黄色参考线提示

### JSON 编辑

- 和图形化**编辑的是同一份数据**，两边**实时同步**
- JSON 写错了只在下方报错，**不会**覆盖图形化的内容，改对后自动生效
- 适合批量修改 / 从别处粘贴数据

### 波形库与管理

- 左上角 **☰ 波形库**：内置示例 + 你自己的波形
- **内置示例是只读的**（可以看、可以照着画着玩，想改请用「另存副本」）
- 打开新波形前会提示覆盖风险，避免误丢正在编辑的内容
- **新建波形**需要先填**名称、循环时长、插值模式**（阶梯 hold / 线性 linear）

### A / B 两条通道

一个波形内部同时含 **A、B 两条通道曲线**，同屏显示：**A 实线、B 虚线**。
新画的点落在哪条通道，由**你点选哪个断点**决定，不需要手动切换通道。

> 详细操作见编辑器右上角的 **「❓ 使用说明」**。

## 🛡️ 安全改进

**切换波形时自动取消该通道的输出勾选，并补发停机指令。**

不同波形产生的刺激强度差异很大，换波形后必须重新确认参数再开输出 —— 现在换波形会自动关断，你重新勾选即可继续（会从波形开头播）。

## 🎨 界面与交互

| 改动 | 说明 |
|---|---|
| 提示升级为弹窗 | 导入结果、导出结果、重命名、改时长、删除确认、编辑器保存 / 另存副本，全部从底部小字改成**显著弹窗** |
| 重命名 / 改时长 | 不再用浏览器原生弹窗，换成**统一样式的输入框** |
| 按钮改名 | 工具栏「📥 导入 / 导出」→「**📥 导入 / 导出 / 管理**」 |
| 提示精简 | 选波形的提示去掉了多余的括号说明 |
| 新增提示条 | 顶部加了一条「**保持前台运行**」，点右边的 `?` 看说明 |

## ⚠️ 关于「保持前台运行」

这一版**切换标签页、把浏览器挂到后台不会停止动作**了，玩具会继续跑。但有个浏览器层面的限制要知道：

> 页面切到后台时，**浏览器会把后台页面的定时器降频**，蓝牙发包速度会从 **20 次/秒** 降到 **约 1 次/秒**（Chromium 强制规定 `1s/次`）。

表现就是**动作会变得一顿一顿**，**波形周期越短越明显**；回到前台立刻恢复正常速度。所以长时间使用时，建议保持页面在前台。

## 📌 已知限制（两个版本通用）

- 只支持 **Chrome / Edge**（Firefox / Safari 不支持 Web Bluetooth）
- **BLE 单连接**：脚本播放器和波形控制器**不能同时控制同一台玩具**
- 有效波形频率上限约 **10Hz**（每 50ms 发一包）
- 数据存在**浏览器本地**：清缓存 / 换浏览器 / 换域名都会丢 —— 请用「导入 / 导出 / 管理」定期备份
- 波形控制器目前仍是 **v2.0 Beta**
- 波形编辑器**新增**，如果有问题欢迎反馈
