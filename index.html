📖 使用教程

步骤 — 连接蓝牙

确保 ESP32 已上电。点击 "🔵 连接蓝牙" 按钮，浏览器会弹出设备选择窗口。
选择设备完成配对。连接成功后右上角显示 "已连接"。

步骤 — 打开文件夹

点击 "📁 打开文件夹"，选择存放媒体文件的文件夹。
文件夹中需要包含：

  • 媒体文件：.mp4 / .mp3 / .webm 等
  • 同名 CSV 脚本文件
  • 同名 VTT 字幕文件（可选）

📌 例如：video1.mp4 + video1.csv + video1.vtt

步骤 4 — 开始播放

点击工具栏的 ☰ 播放列表 打开播放列表抽屉，在列表里点击一个文件即可选中；视频加载完成后点击 ▶ 播放按钮。

抽屉右上角的 ✕ 关闭 / 点抽屉外的遮罩 / 按 Esc 都可以收起抽屉。

底部波形图会显示脚本动作的强度预览，白色竖线是当前播放进度。

📌 播放完当前文件后，会自动切换到播放列表中的下一首。

📌 如果感觉左右电机方向反了，点击工具栏上的 🔀 交换左右电机 即可。

📂 CSV 脚本格式说明

程序支持两种常见的 CSV 格式：

  • （5 列）：时间戳, 左方向, 左速度, 右方向, 右速度
  • （3 列）：时间戳, 方向, 速度（左右同时运动）

方向：0 = 正向旋转，1 = 反向旋转。

时间戳 = 数值 × 0.1 秒（例如 6636 = 663.6 秒 ≈ 约 11 分钟）。

❓ 常见问题

  • 搜不到设备？ 确认 ESP32 已上电，并且烧录了正确的 2in1 固件。
  • 连接成功但不动？ 检查 TB6612FNG 驱动板的 STBY 引脚是否拉高（GPIO 10）。
  • 播放列表中没有任何文件？ 文件夹里需要有 .mp4 或 .mp3 等媒体文件。
  • 网页提示不支持蓝牙？ 请更换为 Chrome 或 Edge 浏览器（Firefox / Safari 不支持 Web Bluetooth）。
🌊 波形控制器使用教程

它和「脚本播放器」有什么区别？

脚本：配合视频播放、10~20 分钟的长流程。
波形：几秒到几十秒的短动作模板，选定后会一直循环播放 —— 不联动视频，纯手动控制。

四步开始

  • ① 连蓝牙：点 🔵 连接蓝牙 选 UFO-TW，连上后徽章变「已连接」。连上后引擎自动开始运行（只是时钟在跑，不勾选复选框就完全没有输出）。
  • ② 选波形：点通道卡上的 「选择波形…」，在抽屉里点一个波形。选波形不会开启输出，此时电机不动。
  • ③ 调强度 / 相位：拖 强度 滑杆（10%~150%）决定转速；相位 用来把两通道错开节奏。换波形后刺激强度会变，记得重新调一遍。
  • ④ 勾选启用：确认参数合适后，才勾选通道卡上的复选框开启输出。勾选的瞬间就是这条通道时间轴的起点 —— 每次勾选都从波形开头播放，不会从中间接着跑；取消勾选则时间轴冻结在起点（播放头停住不动）。波形的赋值与启停是分开的 —— 想先预览请用 ▶ 试一下。

两个通道互相独立

A / B 各有自己的波形、强度、相位和启停勾选框，输出由复选框决定。想单独试某个通道，点该卡片的 ▶ 试一下 —— 它会从波形开头完整播放 2 个循环周期（时长 = 波形周期 × 2），结束后自动发出停机指令，并恢复原来的勾选状态。
试听不会改动引擎的启停状态；急停只归急停管 —— 想中止试听直接按 ⏹ 急停 或取消勾选即可。

示波器怎么看

  • 上半 = 正转（青绿），下半 = 反转（品红），中线是 0（停）
  • 淡色曲线 = 波形的目标值；亮色折线 = 真正发出去的指令（每 50ms 一个点）
  • 白色竖线 = 播放头；红色虚线表示「强度 × 原始速度」超过 127 上限，超出的部分会被夹取

⏹ 全部停止：连点两次

这是急停，只留给紧急情况：第一次点击只会让按钮闪一下并提示，0.8 秒内再点一次才会立即归零并让引擎停止。
急停会同时作废正在进行的「试一下」，绝不会稍后自己恢复输出。

🔄 切标签页 / 挂后台

动作不会停 —— 你可以放心切到别的标签页、把浏览器最小化或挂到后台，玩具会继续按波形/脚本动作。
代价：浏览器会把后台页面的定时器降频（约 1 次/秒），所以后台期间发包频率会从 20Hz 掉到约 1Hz，波形周期越短（小于 1 秒）越显得糙。相位是按真实时间推算的，不会错乱，回到前台立刻恢复 20Hz。
想停就取消勾选、或按 ⏹ 急停。关闭页面 / 设备断开时程序仍会尝试发送停止指令。

🌐 远程控制（v3.0）

让别人远程控制你的设备，或你远程控制别人的设备。分两个角色，各自一个页面：

  • 📡 远程被控（谁持有玩具谁开这个）：按引导走三步 —— ① 连接蓝牙 → ② 填远程服务器地址 → ③ 创建房间，会得到一个 8 位房间号。把这个号发给对方即可。
  • 🔗 连接房间（操控的一方开这个）：弹窗里填服务器地址 + 房间号，连上后界面和本地控制一样（波形库、强度、相位、启停、急停）。

要点：

  • 玩具的蓝牙始终由被控方持有，远程只是把「用哪个波形、强度多少、开关」发过去，真正的 20Hz 指令由被控方本机生成
  • 被控方会收到主控方的完整波形（不只是编号），所以可以体验主控自己的私人波形；这些波形在被控方那边标为只读，可以另存副本
  • 主控方连接后自动断开本机蓝牙；主控页面没有「连接蓝牙」按钮（蓝牙由被控方持有），顶部是「🔗 连接房间」，可以随时重连或换房间
  • 切换标签页 / 挂后台不停止动作，但浏览器会把后台页面降频到约 1 次/秒，动作会发涩；建议双方都保持前台
  • 安全底线：被控方急停永远可用且最高优先，按了会锁定，主控无法解除，只有被控方能解锁；与主控失联超过 8 秒、主控离开房间、或与服务器断开，被控方都会立即安全停机。失联导致的停机是临时的 —— 链路恢复、主控一重新下发就自动继续，不需要手动解锁
  • 远程模式下换波形不打断输出（与本地不同），因为主控随时能停、且已失联停机兜底
  • 房间号就是授权：拿到房间号就能加入，请私聊发给对方，不要发到公开频道

远程控制需要一台自己的服务器（用于双方中转）。部署方法与原理见仓库 RemoteServer/ 目录下的部署教程。

导入自己的波形

  • 点工具栏 📥 导入 / 导出 / 管理 →「选择文件」：可单选、可多选、也能直接选波形包（一个 .json 里打包多个波形）
  • 批量：「选择文件夹」 会递归扫描里面的 .json / .csv，不需要压缩包
  • ⚠ CSV 注意：程序底层只使用 JSON，CSV 只是交换格式，导入时会自动转换且是有损的（时间按 0.1 秒、方向 1 → 负值、超过 127 会夹取、3 列则 A/B 相同、正好落在循环点的末尾断点不会播放）。程序会弹出提示让你核对后再确认导入。
  • 导出：单个波形 / 全部打包成一个文件 / 或写入文件夹（每个波形一个文件 + 一份格式说明）

数据存在哪

存在浏览器本地：换浏览器、清缓存、本地打开与线上访问都不共享数据 —— 请用「导出」定期备份。

❓ 常见问题

  • 选了波形没反应？ 这是正常设计：选波形只赋值不输出，还要勾选通道复选框才会开始（未连接蓝牙也能看示波器动，但不会真的输出）。
  • 感觉不到变化？ 每 50ms 才发一包，波形有效频率上限约 10Hz，太快的变化电机跟不上。
  • 能和播放器页同时用吗？ 不能：BLE 是单连接，两个页面不能同时控制同一台设备。
  • 强度拉满还是不够猛？ 说明该波形的原始速度就低（卡片上会显示「原始峰值」），换个峰值更高的波形。
