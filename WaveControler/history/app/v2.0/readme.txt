2026.9.16 波形控制器 v2.0 —— 新增波形编辑器

【新增：波形编辑器】
1. 控制器工具栏新增「✏️ 波形编辑器」，新标签页打开，与控制器共用同一份本地波形数据。
2. 图形化编辑器：网格线 + 幅度轴（±125，每 25 一格，0 居中）+ 时间轴，视图固定为「整周期 × 全幅」，不做缩放平移。
3. 绘制方式：自由绘制（按住左键拖，按 50ms 时间步落点）、两点式折线（点起点再点终点）。
4. 精确落点：状态栏可输入「时间 / 幅度」回车落点，避免鼠标误差。
5. 断点可直接点选拖动，Shift+点击插入，Delete 删除；支持撤销重做（Ctrl+Z / Ctrl+Y，或工具栏 ↶ ↷）。
6. 自动吸附：幅度 0 与 ±127、网格上的每一条刻度、时间 0 与循环终点、已有断点，阈值 6 像素。
7. JSON 编辑器：与图形化编辑同一份数据，双向实时同步；写错只在下方报错，不会覆盖图形化内容。
8. 波形库抽屉：内置示例只读可看不可改，想改请「另存副本」；打开新波形前会提示覆盖风险。
9. 新建波形需先填名称、循环时长、插值模式（阶梯 hold / 线性 linear）。
10. 编辑器保存后控制器会自动同步，无需手动刷新；使用说明见编辑器右上角「❓ 使用说明」。

【安全改进】
切换波形时自动取消该通道的输出勾选并补发停机指令。不同波形的刺激强度差异很大，换波形后必须重新确认参数再开输出。

【界面与交互】
1. 底部提示改为弹窗提示：导入结果、导出结果、重命名、改时长、删除确认、以及编辑器保存与另存副本。
2. 重命名与改时长改用统一样式的输入弹窗，不再使用浏览器原生弹窗。
3. 工具栏「📥 导入 / 导出」改名为「📥 导入 / 导出 / 管理」。
4. 选波形的提示文字精简。
5. 顶部新增「保持前台运行」提示条，点问号可看说明（切后台浏览器会把发包降速到约 1 次/秒）。

【行为变化】
- 切换标签页或挂到后台不再停止动作，玩具会继续运行（会被浏览器降频刷新）。
- 连接设备后引擎自动开始运行；顶部按钮只负责急停 / 暂停，输出完全由两个复选框控制。

【教程同步】首页波形控制器教程已同步以上变化。
【远程控制（可选，需自建服务器）】
1. 控制器工具栏新增「📡 远程被控」和「🔗 连接房间」两个入口。
2. 被控方（持有玩具、连蓝牙的一方）三步创建房间，得到 8 位房间号发给对方。
3. 主控方凭服务器地址 + 房间号加入，界面与本地控制一致，波形库来自主控自己。
4. 玩具的蓝牙始终由被控方持有；主控方下发的只是"用哪个波形、强度、相位、启停"，
   真正的 20Hz 指令由被控方本机生成，所以网络延迟不影响波形质量。
5. 主控方的完整波形会传给被控方（不只是编号），被控方那边标为只读，可另存副本。
6. 主控方连接后自动断开本机蓝牙，且「连接蓝牙」按钮置灰，避免误以为在控制本机设备。
7. 安全：被控方急停永远可用且最高优先，按下即锁定，主控无法解除；
   与主控失联超过 8 秒、主控离开房间、或与服务器断开，被控方一律立即安全停机。
8. 远程模式下换波形不打断输出；状态同步用「变化时发送 + 回执确认 + 心跳保活」。
9. 本功能需要一台中转服务器（供两端连接）。服务器程序独立放在仓库 RemoteServer/ 目录，
   可在自己的服务器上自建，部署教程与协议文档都在该目录内。
10. 没有服务器也能验证：使用两个页面里的「本地调试模式」（同一浏览器的两个标签页直连），
    或打开 WaveControler/tests/remote-selftest.html 跑一遍集成自测。
