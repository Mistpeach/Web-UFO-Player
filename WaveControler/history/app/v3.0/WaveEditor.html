这个页面是做什么的

编辑「波形」—— 几秒到几十秒的循环动作模板。保存后回到控制器页面，A / B 通道就能选到它。
一个波形内部同时含 A、B 两条通道曲线，两条曲线同屏显示：A 实线、B 虚线。

三种打开方式

  • ☰ 波形库：读取内置示例 + 你自己的波形。若编辑区已有打开的文件，会先弹窗确认覆盖。
  • ＋ 新建空白波形：先填名称 / 循环时长 / 插值模式，确认后生成一个空波形开始画。
  • 内置示例是只读的：可以看、可以照着画，但不能改；想改请用「另存副本」。

视图操作

  • 视图固定为「整个循环周期 × ±127 全幅」，不做缩放与平移，画多少就看多少
  • 左侧竖轴是幅度：+125 ~ -125，每 25 一格，0 在正中间（上半 = 正转，下半 = 反转）
  • 底部横轴是时间，刻度按周期自动取整；两端有 0（紫）与循环终点（黄）标记
  • 鼠标在画布上移动时，状态栏会实时显示当前时间与幅度

画波形

  • 自由绘制：按住左键在画布上拖，按 50ms 时间步自动落点（与控制器 20Hz 发包率一致）
  • 两点式折线：点起点 → 点终点，直接连一条直线
  • 坐标输入：状态栏「时间 / 幅度」输入框 + 回车（或点「落点」），把断点精确放到指定坐标 —— 鼠标怕点歪就用这个
  • 点击断点选中，拖动移动，Delete 删除
  • Shift + 点击曲线：在该时间点插入一个断点
  • Ctrl+Z / Ctrl+Y（或工具栏 ↶ ↷）：撤销 / 重做
  • Esc：取消当前的绘制（如取消两点式的起点）

A / B 两条通道

一个波形内部同时含 A、B 两条通道曲线，同屏显示：A 实线、B 虚线。
新画的点落在哪条通道，由你点选哪个断点决定（点了 A 的点就继续编辑 A）；不需要手动切换通道。

自动吸附

鼠标靠近这些位置时会自动吸附（阈值 6 像素）：幅度 0 中线、幅度 ±127 上下限、 网格上的每一条幅度刻度、时间 0、循环终点、网格上的每一条时间刻度、已有断点。
命中时状态栏会提示，画布上会出现黄色参考线。不想要吸附就取消状态栏的「吸附」勾选。

阶梯（hold）与线性（linear）

  • hold：断点之间保持前一个值（阶梯），和旧 CSV 脚本语义一致
  • linear：断点之间线性插值（更顺滑）
  • 在顶栏的「模式」下拉里切换，也可以在 JSON 模式改 mode 字段

JSON 模式

两种模式编辑的是同一份数据，会实时同步。JSON 写法有误时下方会报错，并且不会覆盖图形化内容，改对后自动生效。
duration 是循环周期（秒）；每个断点是 [时间, 幅度]，幅度范围 -127 ~ 127，负值 = 反转。

保存与同步

  • 💾 保存：写回浏览器本地数据，控制器的波形库会自动同步（同源标签页间用 storage 事件通知）
  • 若控制器页面没反应，回到控制器页面刷新一下即可
  • 另存副本：生成一个新 id、名字加「（副本）」，不动原件
  • 数据存在浏览器本地，清缓存会丢 —— 请用控制器页面的「导入 / 导出 / 管理」定期备份
