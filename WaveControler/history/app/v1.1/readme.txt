2026.9.16 波形控制器 v1.1 —— 修复输出控制与试听逻辑

【本次修复】
1. 选波形不再改变输出状态：以前选中波形会自动勾选该通道并开始输出，现在只做赋值，需手动勾选启用。
2. 「试一下」按波形自身周期完整播放 2 个周期（原先写死 2 秒，长波形会被截断），结束自动停。
3. 「试一下」不再干涉引擎启停：急停是急停，试听不会稍后把输出恢复回来。
4. 波形播完显式补发停机指令 0,0：修掉首位不为 0 的波形会让电机一直转的问题。
5. 取消勾选通道时也立即补发停机指令，不必等下一个 50ms tick。
6. 未勾选时示波器播放头停在起始位置，不再空转扫描。
7. 每个通道有独立时间原点：勾选输出时从波形开头播放，不再从波形中段切入。
8. 修掉禁用通道在示波器中轴不停刷白点的问题。

【行为变化】
- 连接设备后引擎自动开始运行；顶部按钮只负责急停 / 暂停，输出完全由两个复选框控制。
- 选波形的顺序变为：选波形 → 调强度与相位 → 勾选启用。
