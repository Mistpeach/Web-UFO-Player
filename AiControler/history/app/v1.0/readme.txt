2026.10.11 AI 控制器 v1.0 —— 用对话控制玩具的第一个版本

【这是什么】
1. 在浏览器里和任意 OpenAI 兼容的大模型聊天，AI 在回复的同时可以决定
   「用哪个波形、多大强度、开哪一路」，也就是让模型直接参与控制。
2. 纯静态、零依赖、零构建，双击 AiApp.html 就能打开（file:// 也行），
   也可以放进打包目录、或放到自己的服务器上。
3. 内核复用了波形控制器：波形模型 / 蓝牙 / 50ms 调度器 / 示波器 / 波形存储
   这几份文件是从 WaveControler 逐字节复制过来的，SHA-256 记在 AiApp.html 顶部注释里。
   BLE 协议与 ScriptPlayer、WaveControler 完全一致，同一台设备三边都能控。
   命名空间：复制来的通用模块用 window.WC，本应用自己的代码用 window.AI。
4. 波形数据来自 WaveControler 的波形库（内置 7 个 + 你自己导入的），
   本应用对 ufo.wave.* **只读**，不会改动波形控制器里的任何数据。

【AI 怎么控制设备】
5. AI 回复的**第一个** ```ufo 围栏块里放一行 JSON：
   {"v":1,"ctrl":{"on":true,"wave":"心跳（双跳）","intensity":45,"ch":"AB"},
    "hint":"试探着开始","branches":["再快一点","轻一些","先停一下"]}
6. 围栏块永远不上屏（哪怕里面是垃圾），流式输出过程中也不会闪出来；
   hint 显示成一条状态提示，branches 变成几个可点的快捷回复。
7. ctrl 里任何一个字段不合法 → **整块作废**，不做「部分生效」也不做「钳制后执行」，
   避免模型写错一个字段、设备却按错误参数动起来。

【安全】
8. 实际输出 = AI 给的比率 ×「我的最大强度」，模型永远越不过这个上限。
9. 「允许 AI 控制」总开关：关掉后 AI 照样能聊天，但它的控制只显示、不执行。
10. 下发前要过六道门禁 —— 急停闩锁 → AI 控制总开关 → ctrl 校验 → 上限乘数
    → 蓝牙就绪 → 写引擎，任一不过就整轮拒绝。
11. 急停沿用波形控制器的实现：0.8 秒内连点两次立即归零，防误触。
12. 默认开启「等待 AI 回复期间保持当前动作」，否则每一轮对话都会中断动作、体感很割裂。

【角色卡与提示词】
13. 角色卡字段：名称 / emoji / 背景设定 / 你扮演 / 用户扮演 / 补充信息与边界 / 偏好波形。
14. 三层提示词：L1 协议契约（固定、只读、每次请求都注入，不可被角色覆盖）
    + L2 角色卡（用户可编辑）+ L3 每轮实时状态；三层每轮重新拼成**一条** system 消息，
    不依赖各家实现不一的「支持多条 system」。
15. L3 刻意不含用户上限与实际输出值，免得模型误以为自己在按某个具体数值输出。
16. 内置角色只读，想改就走「另存副本」——和波形库同一套规矩。

【界面】
17. 主界面就是聊天：流式打字机输出、⏹ 停止生成、分支快捷回复、控制徽章。
18. 手动控制侧栏：选波形 / 强度上限 / 手动强度 / 输出开关 / 试听两周期 / 交换左右 /
    双通道示波器（淡色 = 目标，亮色 = 实发）。
19. AI 可用波形白名单：取消勾选 = AI 看不到也用不了；每个波形可以写一句「AI 说明」，
    会一起注入提示词，且**不会**改动 WaveControler 里的原始数据。
20. 调试面板：跑一遍假 AI（不需要接口和密钥也能看完整流程）、
    看这一轮真正发出去的 system 提示词、清空日志。
21. 未连接蓝牙也能聊天，只是控制不会发到设备。

【接口与隐私】
22. 只做 OpenAI 兼容的对话接口，不绑定任何一家：baseUrl / 路径 / 密钥 / 模型 /
    请求头名称与前缀都能填；接非 OpenAI 形状的服务可用高级里的自定义请求头、
    追加 URL 参数、追加请求体字段，以及「从返回 JSON 的哪个路径取文本」。
23. 密钥只存在本机 localStorage，只发给你自己填的那个地址；调试面板里显示的请求头会打码。
24. 配置（ufo.ai.settings.v1）与角色卡（ufo.ai.role.*）都在浏览器本地，
    换浏览器 / 清缓存 / 无痕模式都会丢。

【环境】
- 仍然是纯静态、零依赖、零构建，全部页面都能直接双击（file://）打开。
- BLE 协议未改动，与既有固件保持兼容。
- 远程控制（v3.x 的那套中转）本版本**尚未**接入。
